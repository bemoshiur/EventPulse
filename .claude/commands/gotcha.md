We hit something painful. Log it before we forget.

1. Ask me:
   - Symptom: what did we observe?
   - Why it happens: what's the actual cause?
   - Fix: how did we resolve it (or are resolving it)?
   - How to avoid: what's the rule going forward?

2. Wait for my answers

3. Draft the entry per the format in `.claude/rules/memory-protocol.md`

4. Show me the draft, get approval, append to `gotchas.md`, commit as `memory: gotcha — <symptom>`

Never wait until session end to log a gotcha. Memory rots fast.
